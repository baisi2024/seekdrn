# 产品管理功能完善设计文档

> 创建日期: 2026-06-07
> 状态: 待审核

## 一、概述

### 背景
当前产品管理功能存在以下问题：
1. **后台产品列表**：无分类/标签筛选、无搜索、无批量操作
2. **后台产品编辑**：新建产品流程简陋、规格/关联Tab只是链接、富文本功能不完善
3. **前端产品列表**：使用硬编码分类、无标签筛选、产品卡片无标签展示
4. **前端产品详情**：无FAQ展示、转化设计不突出、未充分利用关联数据

### 目标
构建完整的产品管理体系：
1. 后台：完整的CRUD、筛选、搜索、批量操作
2. 前端：围绕转化设计的产品展示页面
3. 富文本：支持HTML源码编辑的完善编辑器

### 范围
- 后台产品列表增强
- 后台产品编辑/添加完善
- 富文本编辑器重构
- 前端产品列表更新
- 前端产品详情完善

### 2.2 功能清单

|------|------|----------|

## 四、富文本编辑器重构

### 4.1 功能需求

| 功能 | 描述 |
|------|------|
| HTML源码模式 | 切换查看/编辑HTML源码，支持语法高亮 |
| 完整工具栏 | 格式化、对齐、颜色、媒体、表格等 |
| 媒体库集成 | 从媒体库选择图片/视频 |
| 全屏编辑 | 大内容编辑时切换全屏 |
| 字数统计 | 实时显示字数 |
| 快捷键 | 支持常用快捷键 |

### 4.2 工具栏设计

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│ [撤销][重做] │ [加粗][斜体][下划][删除][代码] │ [H1][H2][H3]                    │
│ [无序][有序][任务][引用] │ [左齐][居中][右齐] │ [链接][图片][视频]              │
│ [表格][分割][代码块] │ [文字色][背景色][清除] │ [HTML][全屏] │ 字数: 156       │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 4.3 组件接口

```typescript
interface RichEditorProps {
  content: string
  onChange: (html: string) => void
  placeholder?: string
  maxLength?: number
  minHeight?: number
  features?: {
    htmlMode?: boolean      // 启用HTML源码模式（默认true）
    fullscreen?: boolean    // 启用全屏模式（默认true）
    mediaLibrary?: boolean  // 启用媒体库（默认true）
    wordCount?: boolean     // 显示字数统计（默认true）
  }
  toolbar?: {
    groups?: ToolbarGroup[]
    exclude?: string[]
  }
}

type ToolbarGroup = 
  | 'history' | 'text' | 'heading' | 'list' 
  | 'align' | 'block' | 'insert' | 'color' | 'tools'
```
