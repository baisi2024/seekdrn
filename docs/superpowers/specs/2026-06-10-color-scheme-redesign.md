# SeekDrone 配色重设计规范

## 概述

将 SeekDrone 全站配色从当前的"传统 B2B 企业风"升级为"深空工业科技风"，对标 SpaceX、DJI 等顶级科技企业，打造专业、前沿、可信赖的工业无人机品牌形象。

## 设计目标

- **品牌感受**：技术先进、专业可靠、前沿创新
- **目标客户**：国防/军方/政府 + 工业/能源/基建 + 安防/执法/应急
- **核心原则**：少即是多，让产品说话

## 配色方案

### 核心色彩

| 角色 | 颜色值 | 用途 | 说明 |
|------|--------|------|------|
| **深空黑** | `#0A0E17` | 页面背景 | 像夜空，神秘、科技、专业 |
| **纯白** | `#FFFFFF` | 主文字 | 高对比度，清晰易读 |
| **电光蓝** | `#0066FF` | CTA/强调 | 科技感，仅用于按钮和重要元素 |
| **深灰** | `#1A1F2E` | 卡片背景 | 区分层级，不抢主色风头 |
| **半透明白** | `rgba(255,255,255,0.5)` | 次要文字 | 辅助信息，降低视觉噪音 |
| **边框白** | `rgba(255,255,255,0.06)` | 边框/分割线 | 极淡，不突兀 |

### 使用规则

- **背景**：深空黑 `#0A0E17`（全局）
- **主文字**：纯白 `#FFFFFF`
- **次要文字**：半透明白 `rgba(255,255,255,0.5)`
- **CTA 按钮**：电光蓝 `#0066FF` + 纯白文字
- **次要按钮**：透明背景 + 白色边框
- **卡片背景**：深灰 `#1A1F2E`
- **边框**：极淡白色 `rgba(255,255,255,0.06)`
- **Hover 状态**：白色文字变亮，或背景微亮

### 禁止

- ❌ 不使用绿色（像环保/农业）
- ❌ 不使用橙色（像电商促销）
- ❌ 不使用渐变（显得廉价）
- ❌ 不使用多种强调色（保持单一焦点）

## 与竞品的差异化

| | DJI 大疆 | SeekDrone |
|--|---------|-----------|
| **定位** | 消费级 | 工业级/B2B |
| **背景** | 深灰 | 深空黑（更深） |
| **主色** | 白色 | 白色 |
| **强调色** | 亮蓝 | 电光蓝（更沉稳） |
| **感觉** | 年轻活力 | 专业可靠 |

## 验收标准

- [ ] 全站背景为深空黑
- [ ] 主文字为纯白，清晰可读
- [ ] CTA 按钮为电光蓝，醒目但不突兀
- [ ] 没有绿色、橙色、渐变等禁用元素
- [ ] 整体感觉专业、科技、前沿
- [ ] 与大疆有明确差异化
