# 案例详情页增强功能设计文档

## 1. 需求概述

基于对现有代码的完整检查，本设计文档旨在增强案例详情页的功能，主要包括：

### 1.1 已确认需求

| 序号 | 需求项 | 状态 | 说明 |
|------|--------|------|------|
| 1 | 自定义视频播放器 | 新增 | 使用 react-player 替换简单HTML5 video标签 |
| 2 | Admin视频管理 | 新增 | 支持视频上传、预览、删除 |
| 3 | Admin素材图片管理 | 新增 | 支持图片上传、删除、排序 |
| 4 | Admin案例编辑页面 | 新增 | 创建完整的案例编辑管理界面 |

### 1.2 保持现状

| 序号 | 功能项 | 原因 |
|------|--------|------|
| 1 | 量化成果展示 | 当前卡片展示已满足需求 |

### 2.3 核心组件设计

#### 2.3.1 VideoPlayer 组件

**文件路径:** `src/components/public/video-player.tsx`

**功能:**
- 封装 react-player，提供统一的视频播放体验
- 支持自定义控件样式
- 支持播放统计
- 响应式设计

**Props:**

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| url | string | 是 | 视频URL |
| poster | string | 否 | 封面图片URL |
| controls | boolean | 否 | 是否显示控件（默认true） |
| autoplay | boolean | 否 | 是否自动播放（默认false） |
| loop | boolean | 否 | 是否循环播放（默认false） |

**使用示例:**
```tsx
<VideoPlayer
  url={caseStudy.video_url}
  poster={caseStudy.images[0]}
  controls
/>
```

#### 2.3.2 案例编辑页面

**文件路径:** `src/app/admin/case-studies/[id]/page.tsx`

**功能模块:**

| 模块 | 功能描述 |
|------|----------|
| 基础信息 | 编辑标题、行业、国家、slug、发布状态 |
| 视频管理 | 上传、预览、删除视频文件 |
| 图片管理 | 上传、预览、删除素材图片 |

## 6. 安全考虑

### 6.1 文件上传安全

| 措施 | 说明 |
|------|------|
| 文件类型验证 | 仅允许图片和视频类型 |
| 文件大小限制 | 最大100MB |
| 文件名处理 | 使用UUID重命名，防止路径遍历 |
| 存储隔离 | 存储在独立的R2桶中 |

### 6.2 访问控制

| 措施 | 说明 |
|------|------|
| Admin路由保护 | 仅授权用户可访问 |
| RLS策略 | 数据库行级安全 |
| API认证 | 使用服务端密钥 |
