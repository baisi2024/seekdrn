3. 多语言方案

3.1 语言支持优先级

第一优先级（立即上线）

代码 语言 覆盖区域 理由
en 英语 全球通用，中东、非洲英语区 默认语言，覆盖所有目标市场
ar 阿拉伯语 中东、北非 目标市场核心语言，低英语渗透率地区的关键信任构建
es 西班牙语 南美（除巴西）、部分非洲 覆盖6亿人口，南美第一商务语言
fr 法语 西北非、撒哈拉以南非洲 非洲近半数国家官方语言，B2B采购刚需
pt 葡萄牙语 巴西、安哥拉、莫桑比克 巴西是南美最大无人机市场，安哥拉能源行业需求旺盛
id 印尼语 印尼 东南亚最大经济体，政府基建项目多，中小城市英语渗透率低

第二优先级（按需扩展）

代码 语言 覆盖区域
th 泰语 泰国
vi 越南语 越南
fa 波斯语 伊朗（需合规审查）

· 用户选择后写入 Cookie，覆盖自动检测

7. API 与后端逻辑

7.1 Demo请求处理 (POST /api/demo-request)

· 输入：姓名、公司、邮箱、国家、关注行业、来源页
· 流程：Zod校验 → 合规筛查 → 写入Supabase inquiries → 飞书通知 → 发送多语言感谢邮件 → 返回成功

7.2 合规筛查逻辑

```typescript
// lib/compliance.ts
const BLOCKED_COUNTRIES = ['North Korea', 'Iran', 'Syria', 'Cuba']

export function screen(country: string, application: string) {
  if (BLOCKED_COUNTRIES.includes(country)) return 'blocked'
  if (application === 'C-UAS' || application === 'Counter-Drone Defense') return 'review_required'
  return 'approved'
}
```

· blocked：直接拒询，不存储数据
· review_required：写入询盘并触发飞书审批流，状态置为 review_required
· approved：正常流转

7.3 飞书集成

· 消息通知：正常询盘通过飞书API发送卡片消息给对应行业销售（根据 application_interest 分配）
· 审批流：反制系统询盘自动创建飞书审批，审批人：销售总监→合规专员；回调 /api/feishu/callback 更新询盘合规状态

7.4 文件上传接口 (POST /api/upload)

· 受 Supabase Auth 保护
· 接收文件，上传至 R2，返回 key 并写入 media 表

7.5 邮件发送服务（集成模板管理）

· 基于 Resend 发送
· 核心函数 sendTemplateEmail(templateKey, to, language, variables)
  1. 从 email_templates 表获取激活模板
  2. 根据语言提取主题和正文HTML
  3. 若模板不存在或未激活，回退到默认模板
  4. 替换变量（用正则全局替换 {{var}}）
  5. 调用 Resend API 发送
· 测试发送接口：POST /api/admin/send-test-email（仅管理员），参数：模板ID、语言、测试邮箱

邮件发送逻辑 (lib/email.ts)

```typescript
import { Resend } from 'resend'
import { supabaseAdmin } from './supabase'

const resend = new Resend(process.env.RESEND_API_KEY)

export async function sendTemplateEmail(
  templateKey: string,
  to: string,
  language: string,
  variables: Record<string, string>
) {
  // 获取激活模板
  const { data: template } = await supabaseAdmin
    .from('email_templates')
    .select('translations, is_active')
    .eq('template_key', templateKey)
    .eq('is_active', true)
    .maybeSingle()

  let subject = 'Thank you from SeekDrone'
  let html = '<p>Thank you for your request.</p>'

  if (template) {
    const t = template.translations[language] || template.translations['en']
    if (t) {
      subject = t.subject
      html = t.body_html
    }
  }

  // 变量替换
  for (const [key, value] of Object.entries(variables)) {
    const regex = new RegExp(`{{${key}}}`, 'g')
    subject = subject.replace(regex, value)
    html = html.replace(regex, value)
  }

  await resend.emails.send({
    from: 'SeekDrone <noreply@seekdrn.com>',
    to,
    subject,
    html,
  })
}
```

中间件伪代码 (middleware.ts)

```typescript
import createMiddleware from 'next-intl/middleware'
import { NextRequest, NextResponse } from 'next/server'

const locales = ['en', 'ar', 'es', 'fr', 'pt', 'id', 'zh']
const intlMiddleware = createMiddleware({ locales, defaultLocale: 'en' })

export async function middleware(request: NextRequest) {
  const country = request.headers.get('cf-ipcountry') || ''
  // 从配置获取中文开启状态（实际可缓存读取）
  const enableChinese = false // 示例，实际动态读取 site_settings
  if (enableChinese && country === 'CN' && !request.cookies.has('preferred_locale')) {
    const url = request.nextUrl.clone()
    url.pathname = '/zh' + url.pathname
    return NextResponse.redirect(url)
  }
  return intlMiddleware(request)
}

export const config = {
  matcher: ['/((?!api|_next|.*\\..*).*)'],
}
```
