❌ 未经设计批准，不得写任何代码
❌ 不得调用实现类 skill (frontend-design, mcp-builder 等)
✅ 唯一后续 skill: writing-plans

❌ 没有测试不得写生产代码
❌ 测试必须先失败，再实现
❌ "太简单不需要测试" = 错误
❌ "稍后再写测试" = 不是 TDD

❌ 不得使用占位符 (TBD, TODO, "稍后实现")
❌ 每步必须包含完整代码
❌ 必须有精确的文件路径

用户: "帮我实现用户认证功能"

Agent: 
1. [自动调用 brainstorming skill]
   → 探索项目结构
   → 问: "需要支持哪些认证方式？"
   → 问: "是否需要记住登录状态？"
   → 提出 2-3 种方案
   → 写 spec 文档
   → 用户确认

2. [自动调用 writing-plans skill]
   → 分解任务
   → 写计划文档

3. [执行 TDD 循环]
   → Task 1: RED - 写测试
   → Task 1: GREEN - 最小实现
   → Task 1: REFACTOR
   → Commit
   → Task 2: ...

4. [调用 requesting-code-review]

## 多 Agent 协作
通过 Task tool 派发子 agent：

- 每个 Task 一个独立的子 agent
- 子 agent 完成后返回结果
- 主 agent 在任务间进行审查
